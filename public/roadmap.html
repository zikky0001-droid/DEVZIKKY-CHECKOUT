🗺️ The next version is built step by step.

This page describes ongoing development areas rather than dated promises. Priorities can change as projects are tested, services evolve and available resources change.

🗺️ CURRENT IMPROVEMENT AREAS

🗺️ Reliability before extra complexity.

The practical next step for a collection of independent tools is to make existing experiences clearer, more dependable and easier to understand.

01

Checkout clarity and operational safety

Keep the purpose of the site clear, explain payment status honestly, preserve verification for existing references and avoid starting a new transaction while merchant eligibility is unresolved.

02

Better diagnostics

Record API errors with request IDs, route, status and timing; capture safe browser-side errors so issues can be traced without recording customer secrets.

03

Currency and checkout information

Keep rate direction, fallback status, NGN settlement and the difference between an estimate and a final charge understandable.

04

Project documentation

Make it easier to understand what each project does, which features are experimental, where the public destination is and where to find its source.

05

Mobile experience and accessibility

Improve navigation, readable layouts, reduced-motion support, keyboard access and feedback states for small screens.
