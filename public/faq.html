DEVZIKKY PAY / QUESTIONS

Clear answers. No guesswork.

These answers describe the current version of the website and the DEVZIKKY TECH project information supplied for it.

What is DEVZIKKY PAY?

DEVZIKKY PAY is a project website in the wider DEVZIKKY TECH ecosystem. It includes a checkout codebase, public statistics, API documentation and a private administrative interface. The site includes a secure checkout for donations and service payments.

Is DEVZIKKY PAY the same as DEVZIKKY TECH?

No. DEVZIKKY TECH is the broader developer identity and project collection. DEVZIKKY PAY is one platform within that ecosystem.

Can I make a donation through this page?

Yes. Use the Donate & Support Us button to open the checkout. Select Donation, enter your details and amount, then continue to Paystack. The server verifies payment references before marking a payment successful.

How are payments confirmed?

The server initializes the Paystack checkout and verifies the transaction reference. A redirect back to the site alone is not proof of a successful payment.

What does the currency rate mean?

The public rates endpoint uses NGN as its base. A value such as USD 0.000743 means approximately 0.000743 US dollars per ₦1. Rates are indicative and can change. The backend's internal calculation uses the reciprocal when converting a foreign-currency amount into NGN.

Are all listed projects guaranteed to be online?

No. The project directory reproduces project descriptions and destinations from the portfolio supplied for this update. Each project is an independent destination and can change availability, features or hosting separately.

Does contributing buy ownership or priority support?

No. Any future voluntary contribution would not transfer project ownership or guarantee a particular feature, delivery date, uptime level or priority access.

How can I help without paying?

You can explore projects, share one that you find useful, report a reproducible issue, suggest documentation fixes or visit the public GitHub profile.

Where can I find more information about DEVZIKKY?

Visit zikkytech.xo.je for the portfolio and GitHub for public repositories.
