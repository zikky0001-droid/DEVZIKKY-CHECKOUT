DEVZIKKY PAY / PUBLIC DEVELOPER REFERENCE

Public API.

A reference for public-safe, read-only GET endpoints. No donor names, email addresses, private notes, Admin records or deployment logs are exposed by this catalogue.

SERVICE STATUS

GET /api/ping

Lightweight liveness check. Does not require a database connection.

{
  "ok": true,
  "status": "alive",
  "service": "DEVZIKKY PAY"
}
READINESS

GET /api/health

Checks database readiness, required schema and configuration presence. Secret values are never returned. Detailed database errors remain in server-side logs.

PAYMENT LIMITS

GET /api/payment-limits

Returns the current configured NGN minimum and maximum transaction amounts, whole-number input policy and checkout toast duration.

{
  "currency": "NGN",
  "minimum_amount_ngn": 100,
  "maximum_amount_ngn": 5000000,
  "whole_numbers_only": true,
  "toast_duration_ms": 5000
}
EXCHANGE RATES

GET /api/rates

Returns supported currency units per one Nigerian naira (base=NGN). NGN is represented by base and is not duplicated inside rates.

GET /api/rate is a compatibility alias for this endpoint.
{
  "base": "NGN",
  "source": "live",
  "rates": {
    "USD": 0.000743,
    "EUR": 0.000663
  }
}

Fallback responses may include a snapshot date. These are reference rates, not guaranteed payment quotes.

PUBLIC STATISTICS

GET /api/stats

Aggregated payment totals and time series. Supported query parameters:

  • from and to — DD/MM/YYYY
  • grain — day, week, month or year
  • download=json — return a pretty-printed JSON attachment
GET /api/stats?from=01/11/2026&to=11/11/2026&grain=day
PUBLIC ACTIVITY EXPORT

GET /api/stats/export

Returns successful payment references, amounts, types, Lagos timestamps and donor notes only when the donor explicitly opted in. Donor names, email addresses and private notes are excluded.

GET /api/stats/export?from=01/11/2026&to=11/11/2026
PAYMENT AMOUNT RULE

Integer amounts only

Payment initialization accepts whole-number amounts only. API clients may send an ungrouped integer such as 5000 or a correctly grouped value such as 5,000. Decimal inputs are rejected; the backend independently validates the amount and converted NGN value before Paystack is called. Validation errors use AMOUNT_WHOLE_NUMBER_REQUIRED, AMOUNT_BELOW_MINIMUM, AMOUNT_ABOVE_MAXIMUM or INVALID_AMOUNT_FORMAT as applicable. Minimum and maximum checks apply to the final NGN amount in kobo after currency conversion and rounding.

{
  "success": false,
  "error": {
    "code": "AMOUNT_WHOLE_NUMBER_REQUIRED",
    "message": "Only whole-number amounts are accepted.",
    "whole_numbers_only": true,
    "minimum_amount_ngn": 100,
    "maximum_amount_ngn": 5000000
  }
}
AUTHENTICATION MODEL

Keep credentials server-side

These public GET endpoints return public-safe data and do not require a secret key. API_KEY is reserved for trusted server-to-server automation. ADMIN_KEY is used only to sign in to the website Control Room; the browser receives a short-lived HttpOnly session cookie afterwards. Never embed either key in HTML, JavaScript or a public repository.

NOT IN THE PUBLIC CATALOGUE

Private and state-changing routes

Admin transaction, export and Vercel log endpoints require an authenticated Admin session and are documented only inside the authenticated Control Room and Runtime Logs page. Payment verification is an operational callback that may update transaction state, so it is intentionally not described as a read-only public API.
