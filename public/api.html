Payment API.

Create NGN payment links from trusted applications.

Initialize an automated payment

Send a POST request to /api/automation/initialize. Include your private API key in the Authorization header. Never expose it in browser code or public repositories.

curl -X POST https://YOUR-DOMAIN/api/automation/initialize \\
  -H "Authorization: Bearer YOUR_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{"amount":5000}'

The amount is in naira. The server supplies the configured email, Anonymous name, Automation note and transaction type. The response contains authorization_url and reference.

Other endpoints

  • GET /api/health or GET /health — readiness check (database, schema and required environment-variable presence)
  • GET /api/ping or GET /ping — lightweight liveness check
  • GET /api/rates (also /api/rate) — exact provider rates plus the separate NGN-per-unit conversion map
  • GET /api/stats — public aggregate statistics
  • POST /api/pay/initialize — website checkout
  • GET /api/pay/verify?reference=... — verify a payment
  • POST /api/webhook — Paystack webhook

Exchange-rate response

rates contains the provider's values exactly as returned for base=NGN: foreign-currency units per ₦1. NGN is represented by the base field and is not duplicated in rates. Live responses omit the snapshot date; cached and static fallback responses include it. The checkout converts using the reciprocal internally; the conversion map is not exposed by this endpoint.

{
  "base": "NGN",
  "rates": { "USD": 0.000743 },
  "ngn_per_unit": { "USD": 1345.9 }
}
