DEVZIKKY PAY / DEVELOPER REFERENCE

Understand the API.

A concise reference for the public endpoints currently exposed by DEVZIKKY PAY. Secrets are server-side only. Payment initialization uses server-side Paystack verification and configurable NGN limits.

LIVENESS & READINESS

Service checks

  • GET /api/ping — lightweight liveness response; does not require a database connection.
  • GET /api/health — readiness check for the database, schema and required environment-variable presence.
  • GET /api/stats — public aggregate transaction statistics, filtered with DD/MM/YYYY dates.
  • GET /api/stats/export?from=DD/MM/YYYY&to=DD/MM/YYYY — public-safe successful transaction export; includes notes only when donors opt in.
  • GET /api/payment-limits — current public NGN minimum and maximum from server configuration.
EXCHANGE RATES

GET /api/rates

The response preserves the rate provider's direction for base=NGN: foreign-currency units per one Nigerian naira. NGN is represented by base and is not duplicated in rates. Currency codes are alphabetically ordered.

{
  "base": "NGN",
  "source": "live",
  "rates": {
    "USD": 0.000743,
    "EUR": 0.000663
  }
}

For example, USD 0.000743 means ₦1 is approximately USD 0.000743. This is a reference rate, not a guaranteed quote. Fallback responses include a snapshot date.

PAYMENT REFERENCES

Verify an existing reference

GET /api/pay/verify?reference=... checks a previously created payment reference. It does not start a new payment.

ⓘ
Payment initialization is available to authorised merchants. POST /api/pay/initialize accepts the optional note (maximum 200 characters) and note_public consent flag, creates a pending transaction and returns a Paystack checkout URL; the server verifies the reference before counting it as successful. Public notes are displayed/exported only when note_public is explicitly true. GET /api/payment-limits returns the public NGN minimum and maximum configured in the server-side config.
WEBHOOKS & ADMIN

Protected application routes

  • POST /api/webhook — Paystack webhook endpoint for previously configured transactions.
  • POST /api/admin/login — administrator authentication.
  • POST /api/admin/logout — end the administrator session.
  • GET /api/admin/transactions — authenticated transaction listing.
  • GET /api/admin/export — authenticated, pretty-printed JSON transaction export.

The private API key and admin key must never be placed in browser code, public HTML or a repository.
