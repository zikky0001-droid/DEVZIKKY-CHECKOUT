🔌 PRIVATE API DIRECTORY

Administrative endpoints

These private routes require the appropriate signed session. Runtime Logs uses its own session; Control Room endpoints retain the Admin session.

POST /api/logs/loginVerify ADMIN_KEY and create the separate Runtime Logs HttpOnly session.
POST /api/logs/logoutEnd only the Runtime Logs session.
GET /api/admin/transactionsRetrieve the latest transaction records.
GET /api/admin/export?status=allDownload matching records as pretty JSON.
GET /api/admin/logs?limit=100&refresh=1Query the official Vercel Observability Events API for up to 100 runtime log entries from the latest production deployment, limited to the previous hour. The API accepts refresh=1 to bypass its short cache.
